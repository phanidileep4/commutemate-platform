- Electron wrappers for both web applications.
- Expo member mobile remains the mobile starting surface.

## Development identity
For local development only, set headers:
- `X-Tenant-Slug: northstar`
- `X-User-Email: admin@northstar.example` or `member@northstar.example`

`DEV_HEADERS_ENABLED` must be false in non-local environments. Production identity will use OIDC/JWT and map the external subject to tenant membership.
