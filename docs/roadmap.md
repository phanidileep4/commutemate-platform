# Build roadmap

## Milestone 1 — Platform foundation (current)
- Multi-tenant domain model
- Tenant policy-driven matching kernel
- Admin/member/mobile/desktop application shells
- PostgreSQL schema
- Local infrastructure
- Privacy principles

## Milestone 2 — Identity + tenant onboarding
- Platform admin creates tenant
- Tenant admin invitation
- OIDC/SSO configuration
- Tenant branding and locations
- Membership + RBAC

## Milestone 3 — Real commute lifecycle
- Profile/preferences
- Ride offer/request
- Candidate generation using geospatial + schedule filters
- Ranked recommendations
- Mutual acceptance
- Notifications
- Ride completion + feedback

## Milestone 4 — Matching intelligence
- Commute-intent weight adaptation
- Repeat-match learning
- Explainable score bands
- Cold-start strategy
- Fairness and diversity constraints
- Abuse/rejection privacy

## Milestone 5 — Parking + organization ROI
- Parking capacity model
- Carpool priority/reservations
- Peak vehicle avoidance
- Incentives
- ESG and sentiment analytics

## Milestone 6 — Production hardening
- PostgreSQL RLS
- Redis caching
- queue/event processing
- observability
- rate limits
- data retention/deletion
- admin audit trails
- security review
